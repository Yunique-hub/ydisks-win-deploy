## 一、A 层：契约操作逐条实测（158 项）

### 方法

`api/openapi.yaml` 是上游 `/api/v1/**` 与 `/health` 的**唯一契约源**（上游 AGENTS.md 明文规定）。
本次把契约解析成「方法 + 路径」清单共 **158 个操作 / 117 条唯一路径**，
对运行中的服务逐个发请求（路径参数用占位值填充，如 `{cid}` → `1`）：

- **401/403** ⇒ 路由已注册且鉴权中间件生效（本系统所有版本化操作都要求登录）
- **404** ⇒ 路由不存在（真实缺失）
- **400/422** ⇒ 路由存在但参数不合法（再换一组取值复测，排除误判）
- **2xx** ⇒ 公开可达

选择这个判据的原因：服务对「不存在的版本化路由」返回 **404**，
对「存在但未登录」返回 **401** —— 两者可清晰区分，因此**不需要管理员密码**也能验证接口完整性。

## 五、唯一失败的用例：上游的跨平台缺陷（不是本次部署的问题）

```text
--- FAIL: TestPublishImageAndSheetHelpersCoverPathAndHeaderBranches (0.06s)
    pure_business_coverage_more_test.go:48: 安全图片路径="folder\\image.png" err=<nil>
```

### 定位

`internal/server/item_publish_images.go` 的 `safeZipPath`：

```go
raw = strings.TrimSpace(strings.ReplaceAll(raw, "\\", "/"))   // 先把 \ 归一成 /
if raw == "" || strings.HasPrefix(raw, "/") { ... }
clean := filepath.Clean(raw)                                   // ← Windows 上又把 / 变回 \
if clean == "." || strings.HasPrefix(clean, ".."+string(os.PathSeparator)) || clean == ".." { ... }
return clean, nil
```

`filepath.Clean` 是**平台相关**的：在 Windows 上分隔符是 `\`，
所以 `"folder/image.png"` 会被规范化成 `"folder\image.png"`。

同一个包里两个用例对**同一个函数**给出了互相冲突的期望：

| 用例 | 断言 | Windows（本机） | Linux（上游 CI） |
|---|---|---|---|
| `pure_business_coverage_more_test.go:47` | `safeZipPath("folder/image.png") == "folder/image.png"` | ✗ 得到 `folder\image.png` | ✓ |
| `parser_test.go:279` | `safeZipPath("images/a.png") == filepath.Join("images","a.png")` | ✓ | ✓ |

也就是说：**这个用例在 Linux 上通过、在 Windows 上必然失败**，
是上游测试自身的平台假设问题，而不是本次部署引入的。

### 影响面（对使用者）

- **不影响已实测通过的所有主流程**：登录、账号、商品、订单、卡密、模板、
  自动化规则、消息回复、通知、看板、日志（见 §1/§2/§3 的 158 + 12 项证据）。
- 只在 **批量铺货（`/app/items` 的铺货批次）里使用「文件夹形式的图片引用」** 时，
  返回值里可能出现 `folder\image.png` 这种反斜杠路径。若上游后续把该返回值用于
  URL 或 ZIP 条目名，可能出现路径不匹配。
- 建议：铺货时优先用**图片 URL** 或**平铺文件名**，避开 `folder/subfolder/x.png` 形式；
  上游修复前不必改动本地代码（改了会与上游契约测试冲突）。

### 复现

```powershell
$env:GOROOT="$PWD\runtime\go"; $env:GOPATH="$PWD\runtime\gopath"; $env:GOCACHE="$PWD\runtime\gocache"
$env:GOPROXY='off'; $env:GOFLAGS='-mod=mod'; $env:GOTOOLCHAIN='local'
cd app
& "$env:GOROOT\bin\go.exe" test ./internal/server -run TestPublishImageAndSheetHelpersCoverPathAndHeaderBranches -v -count=1
cd ..
```
